# ComHub Upstream Customizations

This document records ComHub-specific changes that must be preserved when syncing from upstream LobeHub.

Rule for future changes: every ComHub customization that touches upstream-owned files must add a short entry here before commit. Keep the entry specific enough that a future upstream merge can re-apply or verify the customization quickly.
